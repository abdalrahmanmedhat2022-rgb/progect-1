Loan Data Analysis Using Microsoft Excel

Project Overview

This project focuses on organizing and analyzing loan application data using Microsoft Excel.

The workbook contains three worksheets:

• Sales Officer Information: Contains sales officer IDs, names, email addresses, and page references.
• Loan Details: Contains detailed loan-related data.
• Analysis for Dashboard: Contains summary tables and numerical metrics related to loan applications and disbursements.

Key Metrics

• Count of Signed Applications
• Count of Disbursed Cases
• Total Loan Amount
• Disbursement Ratio
• Disbursement Amount Ratio

Tools Used

• Microsoft Excel

Project Objectives

• Organize loan-related data.
• Summarize key loan application metrics.
• Analyze loan disbursement figures and ratios.
• Present key figures in summary tables.

Project File

Excel workbook containing loan data and analysis tables.
